# User guide

This portal is a fictional demonstration. Do not enter real complaints or personal data.

## Citizen

1. Register or sign in as a citizen.
2. Submit a grievance with district, category, subject, description, and optional JPG/PNG/PDF attachments (5 MB maximum each).
3. Optionally request AI suggestions. They are advisory and are never submitted as official decisions automatically.
4. Keep the `CMK-...` reference. The dashboard displays your records, public updates, and status history; the public tracking page displays only the public view.
5. When resolved, submit one rating and optionally reopen the case with a reason if it still needs attention.

## CMO administrator

Sign in using an operator-provisioned CMO account. Review the queue using status, department, district, category, priority, and text filters. Open a case to begin review, inspect (and accept/override) stored AI suggestions, assign an active officer with an internal note, publish a public update, record an escalation reason, review/return action reports, and resolve only after accepting a report.

## Department officer

Sign in using an operator-provisioned officer account and department. Only active assignments appear. Record internal progress by default; select the checkbox to publish a non-sensitive update to the citizen. Submit an action-taken report. If CMO returns it, address the review note and submit a replacement. Officers cannot resolve or access cases outside active assignments.

## Tracking and privacy

Public tracking requires the exact high-entropy reference. It does not expose grievance description, attachments, internal remarks, officer assignment details, AI review data, or private feedback. Attachment downloads require authenticated authorization even if a download URL is known.
